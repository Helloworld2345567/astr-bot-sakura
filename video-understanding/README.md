# 通用视频理解插件 0.1.1

独立于小樱的通用核心与 AstrBot 4.28.2 插件。使用选定的 Chat Completions 提供商，以 `image_url` 承载实际 `data:video/mp4;base64,...`，保留音轨；当前聊天模型继续按原人格回答。此协议是已选服务的兼容扩展，不能从模型名称推定任意服务支持。

## 构建与安装

在此项目目录执行：

```sh
python scripts/build_plugin.py --output dist/video_understanding-0.1.1.zip
```

通过 AstrBot 插件管理上传 ZIP。安装依赖后，确保 **AstrBot 进程环境** 中的 `ffmpeg`、`ffprobe` 可执行（含 H.264/AAC 编码器）。依赖缺失会返回明确错误。容器需要在镜像中安装 FFmpeg；桌面版需要重启进程以继承 PATH。

在插件配置选择 `analysis_provider_ref`，填写经过 MP4 契约验证的 `openai_chat_completion` 提供商 ID。插件从宿主管理器复用地址、当前 Key 和模型，不读取个人配置文件，不复制密钥，不修改聊天提供商。自定义认证只复用 Bearer Key，以及明确允许的 OpenAI Organization/Project 请求头；其他自定义头和代理暂不支持。提供商地址必须是 HTTPS。

`allowed_scopes` 默认空列表，只有填入完整 UMO 的机器人/会话会处理。可在 AstrBot 会话管理中取得 UMO；不使用通配符。人格需启用本插件的四个工具。普通用户可以使用，无需管理员/Shell 权限。

## 使用

发送一个视频或文件并明确提问，例如“总结视频”“最后发生了什么”“他说了什么”。不只按扩展名判断文件，最终以 ffprobe 实际流为准。支持 HTTPS 附件、宿主本地附件与宿主提供的引用链；无权恢复或过期的引用提示重发，不查询个人会话数据库。暂不接受 Base64 消息组件，改用视频文件上传。

可发送 B站 BV、页面、b23 短链及 `?p=2`，或抖音视频链接和分享短链。解析器只处理目标作品；图集、直播、播放列表、分片流返回明确不支持。解析全部请求使用公共地址校验和 DNS 固定连接，下载重新检查每次重定向及连接。私网、回环、非 HTTPS 被拒绝；遇到登录/风控等请改发文件。管理员可配置 Netscape Cookie 文件，仅供解析器使用；Cookie 不发送给视频模型。平台要求在下载阶段也携带 Cookie 的内容当前不能获取。

明确区间通过工具 `start_seconds`、`end_seconds` 传入；结果时间转换为原片时间。最多分析五分钟，不静默截断。压缩超限、音轨丢失和截断均失败。远程长片仍受整个下载预算约束。

工具：`analyze_video`、`get_video_analysis`、`cancel_video_analysis`、`delete_video_analysis`。一次只处理一个候选，多视频时重发/引用一个以明确选择。短任务等待最多 15 秒；之后返回任务号，稍后请求查询。**第一版使用查询模式，不主动向平台补发结果**，由当前聊天工具循环拥有回复，避免重复回复/配图。进度不会另发独立消息，小樱现有最终回复配图流程保持原状。

## 数据与费用

明确请求的视频会上传到你配置的视频服务商。`FULL_MEDIA` 表示发送了所标范围的媒体，`COMPLETE` 表示处理流程完成；均不保证内容逐帧逐字正确。观察、字幕、听清原话、推测与不确定项分开。工具材料是外部数据，不能授权工具或主机操作。

插件专属数据目录由 AstrBot API 定位，附件默认一小时、结果一天。重启后旧附件引用需要重发，未完成任务标为中断且不自动重发。身份核验覆盖读取、取消、删除；机器人、用户、会话共同隔离。结果缓存包含内容哈希、问题、区间、模型/认证配置摘要、提示/schema 和转换预算。SQLite 配额跨重启保留，UTC 日界限；失败计入次数，已预留的模型时长不退款。默认并发 1，队列 10，每用户 1 个活动任务、每日 10 次，另有时长/管理员总预算。

取消会停止本地工作；上游已收到的请求可能继续计费。删除会清理本地附件和结果，上游保留策略由提供商决定。附件/临时文件受体积和存储预算限制，周期清理失败会再次尝试。任务状态只含安全错误码及 HTTP 状态，不记录或向聊天返回密钥、签名 URL、媒体 Base64、下载错误原文和内部路径。

`PROVIDER_UPSTREAM_ERROR` 表示提供商明确报告上游调用失败，需检查所选模型通道；HTTP 400 本身不能证明视频格式有问题。鉴权失败、限流、请求被拒、端点不存在与服务端错误分别分类。错误体只做有界识别，不回显原文，不自动重发视频。

## 开发与验证

```sh
python -m pip install -e '.[links]'
python -m unittest discover -s tests -p 'test_*.py'
```

核心安装无需 AstrBot；适配层测试另安装 `astrbot==4.28.2`。测试生成合成有声/静音 MP4 并检查真实 FFmpeg 处理，模拟 HTTP 出站检查完整 MP4 契约；不会发送真实模型请求或平台消息。发布 ZIP 的导入测试从干净解包目录导入，测试不依赖个人已安装插件。

本次实现与验收边界详见 [验收记录](docs/acceptance.md)。HTTP/MCP 服务、第二框架适配、分段长视频及专用抖音后端属于后续阶段，当前未实现。

代码为本项目新实现，未复制调研插件代码。`aiohttp`、`yt-dlp` 与 AstrBot 通过依赖安装；第三方许可和 FFmpeg 分发注意事项见 [依赖说明](docs/dependencies.md)。
