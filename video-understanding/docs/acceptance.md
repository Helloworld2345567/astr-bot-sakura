# 实现与验收边界

日期：2026-10-20。版本：0.1.0。以工作区总设计确定的 Chat Completions Gemini 路线实现，不重开模型选型。此文件记录实现范围，测试数字与产物哈希由工作区 artifacts 中的本次验收记录给出。

| 项目 | 状态与依据 |
| --- | --- |
| 独立核心 / 独立 AstrBot ZIP | 已实现；manifest 组装，干净解包后注册入口和四工具导入测试 |
| MP4 MIME / 完整字节 / 音轨 | 本地验证；真实 FFmpeg 有声/静音合成片，模拟出站 HTTP 核对完整 MP4 字节 |
| 区间 / 时间映射 / 转码保音轨 | 本地验证；真实 FFmpeg 探测并裁出指定片段，schema 校验原片偏移 |
| 配额 / 并发 / 排队 / 取消 / 总超时 | 本地测试；含排队超时、取消、单用户活动限制、跨重启配额 |
| schema / 无媒体 / 截断 / 模型错误 | 本地测试；不以 HTTP 200 当成功，不自动重发 |
| 身份 / 附件引用 / 删除 / 缓存 | 本地测试；机器人、用户、会话隔离，摘要结果缓存，重启删除与中断标记 |

| B站 / 抖音获取 | 解析、身份、短链和双流路径已实现；真实正反样本 NOT_RUN，不宣称 M2 平台验收通过 |

| 原人格和小樱配图 | 实现沿用原工具循环回复；无后台主动补发，真实协作 NOT_RUN |
| HTTP / MCP / 第二框架 | 后续 M4，未实现；核心可独立安装，无 AstrBot 依赖 |

设计中“短等待后后台回复”在首版选择其允许的查询模式，适配层不保存可主动投递的 event，不尝试平台主动消息，避免回复所有权冲突。对同一视频可查询旧结果；需要新增声画证据时重新调用分析，附件过期须重发。

固定 yt-dlp 版本是实现依据，支持列表不是实际可下载证明。当前只接受 HTTPS 直接媒体流，不处理 HLS/DASH 分片播放列表、付费/试看/受保护内容或图集；平台与提供商真实验收仍需单独执行。失败只保留分类状态，原始私密响应不进入发布包。
